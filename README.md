# Audatown

Audatown is a fork of Audacity 4, an easy-to-use, multi-track audio editor and recorder for Windows, macOS, GNU/Linux and other operating systems. Compared to Audacity 4 it has the cloud/audio.com integration, MuseHub/Muse promotions, telemetry, update checks and crash reporting removed.

Build instructions are in [BUILDING.md](BUILDING.md). Note that the original Audacity project is separate from this fork: the upstream Audacity sources and documentation are at https://github.com/audacity/audacity and https://www.audacityteam.org.
